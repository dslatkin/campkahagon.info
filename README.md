# campkahagon.info

This project is a maintained port of a friend's website from PHP to SvelteKit
that I took over maintenance for. You can see the live website at
[campkahagon.info](https://campkahagon.info). The markup has been modernized but
the visual design (circa 2000s) has been preserved.

The source for the old website can be found in [this directory](./archive/).
